# Rusty Renderer

`rsr` is a toy renderer implemented in Rust. Its goal is to achieve basic
functionality of [pbrt-v4][pbrt].

## References

- [Physically Based Rendering](https://www.pbr-book.org/4ed/contents)
- [PBR Book Repository](https://github.com/mmp/pbr-book-website)
- [pbrt-v4][pbrt]
- [pbrt-v4 User's Guide](https://pbrt.org/users-guide-v4)
